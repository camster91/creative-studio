FAQ

How is this different from a general image chatbot?

Campaign Factory starts with structured brand rules, verified product facts, approved claims, and a bounded work order. A deterministic readiness gate catches missing inputs before the request reaches the image provider. Prompt Studio remains available when direct control is useful.

Can I publish generated images without review?

No automated image system can guarantee packaging, claims, or channel compliance. Review every output against the real pack, approved claim set, required disclosures, and destination requirements before publication.

Where do my campaign inputs go?

Brand, product, and work-order records are stored in Photogen's owner-scoped application database. Generation requests and supplied images are sent to the configured image provider. See the Privacy page for the current data flow and retention description.

What about my API key — is it safe?

Your Gemini key is stored in your browser's local storage and sent with generation requests. The public deployment requires either a valid key or an eligible signed-in trial credit; it does not silently expose the server key.

Can I run this on my own infrastructure?

It's already a single Docker container — clone the repo, point it at your Gemini key, deploy anywhere. Most teams put it on their existing Coolify / Dokku / Fly.io instance alongside the rest of their stack.
